# 🏘️ ポケットタウン — 小さな町づくりシミュレーション

人口300人ほどの小さな町の町長になり、道路・住宅・商業・工業・公共施設を整えて町を育てる、ブラウザで遊べるターン制の街づくりゲームです。

**住宅を増やす → 人口が増える → 仕事が足りなくなる → 商業・工業を増やす → 税収は増えるが交通量・公害も増える → 公園や公共施設が必要になる → 町がさらに発展する**
というフィードバックループを中心に設計しています。

PC とスマートフォンの両方で遊べ、進行状況はブラウザ（localStorage）に自動保存されます。

**▶ 遊ぶ：https://infini7k-wq.github.io/pocket-town/**
（iPhone では Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように遊べます）

## 公開（GitHub Pages）

- `main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）が lint・型チェック・テストを通したうえで静的ファイルを書き出し、GitHub Pages に公開します。
- 手元で公開用のビルドを確認するときは `npm run build:pages`（`out/` に `/pocket-town/` 以下で動くファイルができます）。
- セーブはブラウザと URL ごとに保存されます。別の端末や URL に移すときは、タイトル画面の「📦 セーブデータの引っ越し」で書き出し → 読み込みをします。

## 起動方法

必要環境：Node.js 20.9 以上

```bash
npm install
npm run dev
```

http://localhost:3000 を開きます。同じ Wi‑Fi の iPhone から開発サーバーに入るときは、`.env.local` に `DEV_ORIGINS=192.168.x.x,マシン名.local` を書きます。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` / `npm start` | 本番ビルド / 起動 |
| `npm run build:pages` | GitHub Pages 用の静的書き出し（`out/`） |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript 型チェック |
| `npm test` | ユニットテスト（Vitest） |
| `npm run check` | 上記すべてを順に実行 |

外部 API・外部 DB は使っていません。

## 遊び方

1. **道路をつなぐ** — 建物は道路に面していないと機能しません（⛔）。役所まで道路がつながっていないと効率が半分になります（⚠️）。道路はドラッグで連続して引けます。
2. **住む・働く場所をつくる** — 住宅・商業・工業を置くと「造成中🚧」になり、翌月に建物が建ちます。「街の状況」タブの **建設の需要** メーターが「高い」ものが狙い目です。
3. **翌月へ ▶** — 1か月分のシミュレーションが進みます（人口の転入・転出 → 税収 → 維持費 → 建物の成長 → 雇用 → 満足度 → ランダムイベント）。
4. **住民の声を聞く** — 町の問題点と解決のヒントを住民が教えてくれます。「📍 場所を見る」で問題の場所が地図上で光り、「🏫 学校を建てる」などのボタンで解決に使う建物をすぐに選べます。

ミッションを終えたあとは **🧭 今月のおすすめ** が、いまの街で次にやるとよいこと（赤字の立て直し・足りない施設・需要の高いゾーンなど）を1つだけ提案します（スマホは地図の上に1行で表示）。困りごとが解決すると、住民がお礼を言ってくれます。

最初は画面右上（スマホは地図の上）の **🎯 ミッション** が、道路 → 住宅 → 翌月へ → お店・工場 → 公園 → 学校・病院 → 建物の成長 → 人口500人 → 町へのランクアップ、と順番に案内します（達成ごとに報酬あり）。

地図の見かた：建物の右下の数字がレベル（1〜4）、✨ はもうすぐ育つ建物です。表示モード（交通・環境・満足度・施設の範囲）を切り替えると、地図の下にその色が何を意味するかの説明が出ます。

**施設の範囲**（公園・学校・病院・消防・バス・買い物）を選ぶと、範囲が枠線で囲まれ、効果が届いている住宅に ✓、届いていない住宅に ✗ がつきます。効果は直線距離で届き、道路や川をはさんでも届きます（2×2の施設は建物の端から数えます）。公共施設を置く前は、紫の枠で届く範囲をプレビューできます。「？ 遊び方」の **置き方のコツ** に、住宅・公園・お店・工場・学校・バス停の配置のベストプラクティスをまとめています。

### 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 建設 | 地図の左の建設パレット（操作・道路・住む/働く場所・町の施設・大型プロジェクト）で選んでクリック / ドラッグ | 画面下の建設メニュー（調べる・撤去は左に固定、ほかは「道路・土地 / 町の施設 / 大型」のタブ）。道路や土地はなぞると **下書き** になり、合計費用を見て「✓ 建設」で確定。**2本指で地図・画面を動かせる**。町の施設は1回目のタップで費用と範囲を確認し、2回目で建設 |
| 詳細を見る | 「調べる」でマスをクリック（右パネルに表示） | 「調べる」でタップ（下からシートで表示） |
| 取り消し | ↩️ 戻す（⌘Z / Ctrl+Z）。今月の操作をひとつずつ戻せます | ↩️ 戻す |
| まとめて進める | ⏩ 3か月（イベント・ランクアップ・時代の転換などがあれば途中で止まる） | 同左 |
| 建て替え | 住宅・商業・工業の詳細パネルから、撤去せずに別のゾーンへ | 同左 |
| 撤去 | 🚜 撤去 ツール、または詳細パネルの撤去ボタン | 同左 |
| 表示切り替え | 地図上の 交通 / 環境 / 満足度 / 公園 / 学校 … | 同左 |
| 拡大 | ふだんは街全体を画面の高さいっぱいに表示。🔍 拡大 / 🗺️ 全体 で切り替え | 大きな街では自動で拡大。調べる・町の施設のときは1本指、道路や土地のときは2本指で地図を動かせる |
| ショートカット | 1〜9・0 で建設ツール、B 撤去、Esc 調べる、N / Enter 翌月へ、⌘Z / Ctrl+Z 戻す | — |

建物の詳細パネルには、**次のレベルへの条件チェックリスト**（✅/⬜）、**満足度の内訳**、住宅なら **届いている施設**（✓/✗）が表示されます。月のまとめには、人が出ていった主な理由（仕事がない・住みにくい・道路がない など）も表示されます。

**住宅・お店・工場（民間）と町の施設**：住宅・お店・工場は土地を用意すると住民や会社が建て、維持費はかかりません。公園・学校・病院・バス停などの **町の施設** は町のお金で建て、毎月維持費を払います（撤去すると建設費の40%が戻る）。

**お店の大きさ**：お店は 🏪 コンビニ → 🛒 スーパー → 🏬 デパート → 🏙️ 複合ビル と育ちますが、大きな店になるには周り4マスに住む人が必要です（スーパー150人・デパート600人・複合ビル1,500人）。郊外はコンビニのまま、人の多い中心部にだけデパートが育ちます。⛲ 広場の近くなら必要な人数が半分になり、大きな店ほど遠く（3〜5マス）から客が来ます。

**需要メーター**：「不足 / 少し不足 / ✓ 足りている / 空きあり」の4段階。造成中の区画も数に入るので、建てるとすぐにメーターが下がります。住宅は「空き部屋が転入の何か月分あるか」、お店・工場は「働き手の余力も考えて、あと何区画成り立つか」で決まります。

**町の個性ごとの専用施設**（町ランクで解禁・1つの街に1つ）：郊外住宅地は 🌲 森林公園、工業の町は 🏗️ 産業コンビナート、海沿いの町は ⛵ マリーナ（水辺に面して建てる）、商店街の町は 🏮 アーケード商店街。新幹線駅は線路がとなり町へ続くよう、地図の端に建てます。

### ゲームの仕組み（要点）

| 要素 | 内容 |
| --- | --- |
| 人口 | 住宅を置くだけでは増えません。満足度で各住宅の「目標入居数」が決まり、**仕事の空き**が多いほど転入枠が増えます。失業が多いと失業者が出ていきます。毎月の転入・転出を表示します。 |
| 雇用 | 働き手（人口の50%）と雇用枠（商業・工業・公共施設）を比較。失業 → 満足度・税収が下がる／人手不足 → 商業・工業が育たない。 |
| 商業・工業の需要 | 商業は人口が少ないとお客さんが足りず効率が落ちます。工業は外からの注文（町の個性・イベント・税率で変動）。 |
| 満足度 | 公園・学校・病院・消防・買い物・環境・水辺の景色・騒音・渋滞・失業・税率などの合計（マスごと）。 |
| 環境 | 工業（半径3マス）と交通量で悪化、森・公園・水辺で改善。 |
| 交通 | 建物ごとの交通量を隣の道路に割り当て、道路網に拡散させる簡易モデル。道路1マスごとに 空いている / やや混雑 / 渋滞。渋滞は満足度と商業・工業の効率を下げます。 |
| 建物の成長 | 造成中 → Lv1 → Lv2 → Lv3（例：戸建て → 集合住宅 → マンション）。成長ポイントが貯まり条件を満たすと成長、条件が悪いと衰退・空き家化します。 |
| 財政 | 収入＝住宅税・商業税・工業税（税率は0〜20%で調整可）。支出＝道路と公共施設の維持費・行政サービス費（大きな町ほど1人あたりが高い）・利息。 |
| 立て直し | 借入（ランクで上限拡大）・増税・公共施設の売却（撤去で40%返金）。資金マイナスが **6か月連続** で財政破綻（ゲームオーバー）。 |

### 街が育ってからも続く仕掛け

- **⏳ 時代の転換** — 5〜7年ごとに「高度成長」「脱工業化」「IT革命」「高齢化」「環境の時代」「観光ブーム」「子育ての時代」「低成長」のいずれかに移り変わります。時代によって工業・商業の需要や、学校・病院・環境・公園の効き目が大きく変わります（例：脱工業化の時代は工場が衰退し、オフィスが求められる）。**1年前に予告** されるので、街を作り変えて備えます。
- **📋 陳情・依頼** — 「8か月以内に渋滞を15%以下に」「住民の9割を病院の範囲内に」など、街の状態に合わせた期限つきの依頼が届きます（同時に2件まで）。期限内にかなえると報酬と満足度、失敗すると満足度が下がります。
- **🏗️ 大型プロジェクト（2×2マス）** — 数か月の工事を経て完成し、街全体に大きな効果を与えます。1つの街に1つずつ。

| プロジェクト | 解禁 | 工事 | 完成後の効果 |
| --- | --- | --- | --- |
| 🏟️ スタジアム | 市 | 6か月 | 入場料収入・商業の需要・周りの満足度（交通量も増える） |
| 🎓 大学 | 市 | 8か月 | 半径8マスが学校の範囲に・転入しやすさ・商業の需要 |
| 🚄 新幹線駅 | 市 | 10か月 | 転入しやすさが大きくUP・商業と工業の需要・周りの渋滞緩和 |
| 🎢 テーマパーク | 大都市 | 10か月 | 大きな入場料収入・商業の需要（大量の交通が発生） |
| ✈️ 空港 | 大都市 | 12か月 | 工業・商業の需要が大きくUP（周りに大きな騒音と公害） |

- **ミッションのあと** は「🚀 次の大きな目標」（次のランク・まだ建てていない大型プロジェクト）が表示されます。

### 目標は一つではない

「目標」タブには、**黒字経営・幸せな街・緑の街・マンションの街・商業都市・工業都市・完全雇用・安心の街・渋滞ゼロの街・財政豊かな街** の10種類の「街のスタイル」があり、達成すると報酬がもらえます。町の現在の特徴は「🌳 緑ゆたかな商業の町」のような称号で表示されます。

### メガシティのその先

- **🏅 街の評価（1000点満点・S〜D）** — 人口・満足度・環境・財政・交通・雇用・達成した目標から総合評価します。「目標」タブで内訳と伸ばしどころが見られます。大きいだけの街では S になりません。
- **追加の目標** — 🌃 人口2万人・🏅 評価S・📜 100年続く街。
- **🏛️ 殿堂（思い出の街）** — メガシティに到達した街やチャレンジの記録が、タイトル画面に残ります（年数・最大人口・評価・称号）。大都市以上なら「目標」タブから好きなときに記録することもできます。記録はセーブデータとは別に保存されるので、新しい町を始めても消えません。

### 🎯 チャレンジ（シナリオ）

タイトル画面で「チャレンジ」を選ぶと、特別な状況から期限つきの目標を目指します。早く達成するほど星が多く（制限時間の半分以内で★3、3/4以内で★2）、最高記録がタイトル画面に表示されます。達成・失敗のあとも、そのまま自由に遊び続けられます。

| チャレンジ | 始まりの状況 | 目標 |
| --- | --- | --- |
| 💸 借金からの再建 | 上限いっぱいの借金と空っぽの金庫 | 6年以内に借入を完済し、資金 ¥3,000,000 |
| 👴 限界集落を救え | 空き家だらけ・高齢化の時代 | 5年以内に人口800人 |
| 🏭 工業の町を緑の町に | 商店まで工場になった工業の町 | 8年以内に人口1,200人・環境75以上 |
| 🌋 災害からの復興 | 大地震で町の半分が空き家、資金も少ない | 5年以内に人口600人・空き家ゼロ |
| 🌿 環境都市コンテスト | 郊外住宅地 | 12年以内に人口3,000人・環境80・満足度80% |
| ⏱️ メガシティ最短記録 | ふつうの町 | 40年以内にメガシティ（18年以内で★3・25年以内で★2） |

### 毎回違う町

ニューゲーム時に、町の個性（🌊海沿いの町 / 🏭工業の町 / 🌳郊外住宅地 / 🏮商店街の町）、住民の傾向（子育て世代・お年寄り・環境意識など）、地価、商業・工業需要、初期資金、地形（海・池・森）がランダムに決まります。スタート画面の「🎲 別の町を探す」で選び直せます。

### ランダムイベント（38種類）

良いイベント（地元企業の進出・人気店オープン・観光客増加・補助金・ベビーブーム など）、悪いイベント（火災・工場事故・景気後退・台風・感染症 など）、選択式イベント（大型モール進出・工場誘致・騒音苦情・道路の老朽化・夏祭り・再開発・大学誘致・減税の陳情・大企業の撤退・隣町の開発・万博 など）があります。大地震・洪水などの大きな災害もあります。同じイベントは一定期間（原則18か月）起きず、いまの時代に合ったイベントが起きやすくなります。起きやすさは町の状態で変わります（例：消防の範囲外の建物が多いほど火災が起きやすい、海沿いは台風が多い）。

```
    ├── traffic.ts            # 交通エンジン
    ├── environment.ts        # 環境・騒音
    ├── population.ts         # 人口エンジン（満足度・転入・転出）
    ├── economy.ts            # 財政エンジン
    ├── analysis.ts           # 上記をまとめて街の状態を分析
    ├── growth.ts             # 建物の成長・衰退
    ├── events.ts             # イベントエンジン
    ├── voices.ts             # 住民の声（困りごと → ヒント → 解決したらお礼）
    ├── advice.ts             # 今月のおすすめ（次にやることを1つ提案）
    ├── goals.ts              # 目標（街のスタイル）とミッション
    ├── eras.ts               # 時代の転換
    ├── requests.ts           # 陳情・依頼
    ├── score.ts              # 街の評価（1000点満点）
    ├── scenarios.ts          # チャレンジ（シナリオ）
    ├── hall.ts               # 殿堂（思い出の街の記録）
    ├── progression.ts        # ランクとアンロック
    ├── traits.ts             # 町の個性
    ├── modifiers.ts          # イベントによる一時効果
    ├── actions.ts            # プレイヤー操作（建設・撤去・建て替え・税率・借入）
    ├── simulation.ts         # 月次処理
    ├── state.ts              # 初期の町の生成
    ├── save.ts               # localStorage セーブ／ロード（version + 移行処理）
    └── __tests__/            # ユニットテスト
```

- ゲームロジックは `src/game` にあり、React に依存しない純粋関数です。操作と月次処理は新しい `GameState` を返します。
- 乱数はシード付き（mulberry32）で状態に保存され、同じ状態からは同じ結果が再現されます。
- セーブデータは `version` を持ち、構造を変えたときは `save.ts` の `migrateSave` に変換処理を追加します（v1 の16×16の街は、v2 の24×24マップの中央に移して読み込みます）。読めないセーブデータ（新しいバージョンで保存されたものなど）は、上書きする前に `pocket-town/save-backup` へ退避します。
- テストには、需要メーターを見て建物を置く簡単な自動プレイヤー（`__tests__/bot.ts`）があり、成長・安定性・破綻しないことを確認しています。
  バランスの推移を確認したいときは `BALANCE=1 npx vitest run src/game/__tests__/balance-report.test.ts --silent=false --reporter=verbose` を実行します。
